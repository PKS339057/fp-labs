# ЛР1. Haskell: задачи Project Euler 6 и 15

## Условия

**Задача 6.** Найти разность между квадратом суммы и суммой квадратов натуральных чисел
от 1 до 100. Ответ: 25164150.

**Задача 15.** Сколько маршрутов ведёт из левого верхнего угла сетки 20×20 клеток в правый
нижний, если ходить только вправо и вниз? Ответ: 137846528820.

## Запуск

Нужны GHC 9.6, HLint 3.8, Fourmolu 0.19, make и python3.

```bash
make run     # все варианты обеих задач
make check   # форматирование, HLint, сборка с -Wall -Werror, тесты
make repl    # GHCi с модулями задач
```

Если инструменты не в `PATH`, пути передаются переменными: `make check GHC=... HLINT=... FOURMOLU=...`.

## Реализации

| Требование | Задача 6 | Задача 15 |
| --- | --- | --- |
| Хвостовая рекурсия | `sumSquareTail` | `pathsTail` |
| Обычная рекурсия | `sumSquareRecursive` | `pathsRecursive` |
| Генерация → фильтрация → свёртка | `sumSquareModular` | `pathsModular` |
| Отображение `map` | `sumSquareMap` | `pathsMap` |
| Синтаксис цикла: списковое включение | `sumSquareComprehension` | `pathsComprehension` |
| Бесконечный список | `sumSquareInfinite` | `pathsInfinite` |
| Традиционный язык | `python/euler.py` | `python/euler.py` |

Задача 6 в модульном варианте: (1 + … + n)² — это сумма произведений i·j по всем парам;
пары с i = j дают сумму квадратов, поэтому фильтр оставляет пары с i ≠ j.

Задача 15: маршрут — 2n шагов, из них n вправо, поэтому ответ C(2n, n) = (n+1)…(2n) / n!.
Вариант с бесконечным списком берёт C(2n, n) из середины строки 2n треугольника Паскаля.

## Проверка

`test/Spec.hs`: известные ответы; для задачи 6 — сверка с формулами суммы и суммы квадратов
при n = 1…150; для задачи 15 — сверка с прямым перебором маршрутов на сетках до 6×6 и ответ
для 40×40, который больше 64 бит. `python/test_euler.py` проверяет решения на Python.
CI запускает `make check` при каждом пуше.
